# Evaluación de Degradación en Módulos Fotovoltaicos mediante Dosis Térmica (D)

Repositorio oficial del equipo para el análisis de regresión OLS comparando el modelo empírico tradicional (H_POA) frente al modelo físico con dosis de activación térmica (D_weighted).

## 📁 Estructura del Repositorio
- `data/`: Datasets meteorológicos y de producción regional.
- `scripts/`: Código fuente para la ingeniería de características (cálculo de D).
- `notebooks/`: Entornos de experimentación para los modelos OLS.
